Automatic pricing
When this is on, every price shown on the Calendar goes live automatically on the bot's next run (3am/12pm/8pm Tulum) — guardrailed only by each room type's Min/Max on Rooms Setup. There is no cap on how much a price can move between runs. Turn this off any time to go back to reviewing prices by hand.
